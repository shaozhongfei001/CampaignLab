## 1. 接口签名（4 个 jobs operationId；`getHealth` 归 M0-02，本卡只交付其 `worker` 字段真值来源）
- 通用约定（全部沿用 M0-02-design §1 冻结口径，不得另立）：路由函数只做「解析 → 调 `worker/service.py` → 组装响应」，**不得写 SQL**（PYTHON.md:5）；装饰器必须显式给 `operation_id`，函数名与 operationId 逐字对应（`list_jobs/listJobs`、`get_job/getJob`、`cancel_job/cancelJob`、`retry_job/retryJob`）；返回类型统一 `Response`；每响应必带 `X-Request-Id`（`new_request_id()`＝`uuid4().hex`）；对象响应必带 `ETag: "<revision>"`（`api/common.py::etag`）；错误一律 `application/problem+json`（`problem_response`）；鉴权 `actor: Session = Depends(require_session)`（`api/deps.py`，**只 import 不修改**）；服务注入用本卡新增的 `worker/deps.py::get_job_service`（`api/deps.py` 不在 scope_allow，故不加符号）。
- `listJobs` GET `/api/v1/workspaces/{workspace_id}/jobs` — `async def list_jobs(workspace_id: str = Path(min_length=1, max_length=96, pattern=RESOURCE_ID_RE), cursor: str | None = Query(None, min_length=1, max_length=300), limit: int = Query(25, ge=1, le=100), q: str | None = Query(None, min_length=1, max_length=100), status: str | None = Query(None, min_length=1, max_length=60), actor: Session = Depends(require_session), svc: JobService = Depends(get_job_service)) -> Response`：200 `JobPage{items(0–100), next_cursor}`；排序固定 `created_at DESC, id ASC`、键集谓词 `created_at < :k0 OR (created_at = :k0 AND id > :k1)`、每页取 `limit+1` 判 `next_cursor`（**与 listWorkspaces 同口径**，以复用同一份冻结游标实现）；游标 payload 复用 `encode_cursor/decode_cursor`：`{"v":1,"q":sha256(canonical_json({workspace_id,limit,q,status}))[:16],"k":[created_at,id],"s":actor_id}` → 改任一筛选或换 actor 即 400 `BAD_CURSOR`；`status` 为逗号分隔多值（6 态名全连恰 58 字符 ≤60，见 N7①）；`q` 对 `id`/`kind`/`stage` 做 NFKC+casefold 子串匹配；无结果 → `items=[]`、`next_cursor=null`。
- `getJob` GET `/api/v1/workspaces/{workspace_id}/jobs/{job_id}` — `async def get_job(workspace_id: str = Path(...), job_id: str = Path(...), actor: Session = Depends(require_session), svc: JobService = Depends(get_job_service)) -> Response`：200 `Job` ＋ `ETag`；只读短连接、**不开 `BEGIN IMMEDIATE`**；终态重复查询必须逐字节一致（JOBS.md:23）。
- `cancelJob` POST `/api/v1/workspaces/{workspace_id}/jobs/{job_id}/cancel` — `async def cancel_job(workspace_id: str = Path(...), job_id: str = Path(...), idempotency_key: str = Header(alias="Idempotency-Key", min_length=8, max_length=128), if_match: str = Header(alias="If-Match", min_length=3, max_length=32, pattern=r'^"[1-9][0-9]*"$'), actor: Session = Depends(require_session), svc: JobService = Depends(get_job_service)) -> Response`：200 `Job` ＋ `ETag`（**非 204**，契约只声明 200）；幂等重放逐字节相同（含 ETag）。
- `retryJob` POST `/api/v1/workspaces/{workspace_id}/jobs/{job_id}/retry` — 参数同 `cancelJob`（`Idempotency-Key` 与 `If-Match` 均 required）：202 `Job`（新作业）＋ `Location: /api/v1/workspaces/{workspace_id}/jobs/{new_job_id}` ＋ `ETag: "1"`，必须走 `api/common.py::accepted_response(job, location)`（M0-02 冻结，Q2 口径）。
- `getHealth` GET `/api/v1/health` — 路由与 `Health` DTO 归 M0-02（`api/health.py:get_health`、`application/health_service.py:HealthService`），**M0-04 不得重复注册路由、不得改其错误映射**（`security:[]`，仅 500 `INTERNAL_ERROR` 可达）。本卡只交付其 `worker` 字段的真值来源：`worker/runner.py::WorkerRunner.beat(now)` 在每轮 `poll_once()` 后写心跳，`Health.worker = "READY" iff (clock.now() - heartbeat_at) <= WORKER_HEARTBEAT_TTL_SECONDS(15)`（M0-02-design §4 冻结），循环体抛异常必须置 `failed=True` 使 `worker` 立即 `OFFLINE`、`status` 降 `DEGRADED`。接线缺口见 N3。
- 共享受理入口（**public_frozen 面，M1/M2 全部 202 端点唯一执行者**）：`worker/store.py::JobStore.enqueue(conn, *, workspace_id: str, kind: JobKind, input_json: dict, actor_id: str, idem_key: str, now: datetime) -> JobRow` —— 内含 429 容量闸、`input_digest=sha256(canonical_json(input_json))`、`idempotency` 登记；M1/M2 **不得**各自写 `jobs` 的 INSERT。

## 2. 数据结构（字段级；DTO 一律 `model_config = ConfigDict(extra="forbid")`）
- `Job`（切片 getJob/cancelJob/retryJob 的 `schemas.Job`，13 字段全必填含 null、`additionalProperties:false`）：`id`(1–96，ID 正则)｜`revision`(int 1–9007199254740991)｜`created_at`(datetime，必须 tz-aware)｜`kind`(10 枚举 `VALIDATE_IMPORT,PUBLISH_IMPORT,CORRECT_SNAPSHOT,COMPARE,REVIEW,DIAGNOSE,QUESTION,SIMULATE,REPORT,EXPORT`)｜`state`(6 枚举 `QUEUED,RUNNING,CANCEL_REQUESTED,SUCCEEDED,FAILED,CANCELLED`)｜`attempt`(int 0–9000000000000)｜`progress`(int 0–100)｜`stage`(str 1–120)｜`input_digest`(`^[0-9a-f]{64}$`)｜`retry_of`(str|null)｜`result_ref`(`ObjectRef`|null)｜`problem`(`Problem`|null)｜`retryable`(bool)。**`lease_token`/`lease_until` 不在 schema 内 → 严禁出现在任何 HTTP 体**（`additionalProperties:false` 会直接判红），只存 `jobs` 列（卡内 `inputs.fixtures` 提的 `lease_until` 口径即指此内部列，N1）。
- `ObjectRef`（切片 TRUNCATED，已定向补取）：`kind` ∈ 21 枚举（`workspace,activity,rule,import,snapshot,definition,case,run,candidate,preflight,receipt,comparison,review,diagnosis,question,report,action,job,export,evidence`）｜`id`(1–96，ID 正则)，2 字段必填、`extra="forbid"`。`Problem`（7 字段全必填）/`Issue`（4 字段全必填，`severity ∈ ERROR,WARNING,INFO`，`location` 为 JSON Pointer 如 `/query/status`、`/header/If-Match`）：沿用 M0-02-design §2 冻结定义；`type = "urn:campaignlab:problem:" + code.lower()`（ADR-005 §2.1），`title` 取注册表固定中文短句、**禁调用点现编**，`detail` 才带上下文。
- `jobs` 行口径（`ddl.jobs`，STRICT）：`state` CHECK 6 值｜**CHECK `(state IN ('RUNNING','CANCEL_REQUESTED')) = (lease_token IS NOT NULL AND lease_until IS NOT NULL)` → T2/T5/T6/T7/T8 落终态必须同一条 UPDATE 内把 `lease_token`、`lease_until` 一起置 NULL**（flash 最易漏，漏则 IntegrityError）｜**CHECK `(state='SUCCEEDED') = (result_json IS NOT NULL)` → 只有 SUCCEEDED 可写 `result_json`，FAILED 一律写 NULL**（部分可比、预发差异、规则检查命中只能作为**成功**作业输出，JOBS.md:5）｜`attempt>=0`（入队=0，T1 递增 → 首次执行=1，重试新作业重新从 0 起）｜`progress BETWEEN 0 AND 100`｜`retryable IN (0,1)`｜`input_digest` 长度 64｜`revision>=1`（每次写 +1，即 ETag 值）｜`stage` NOT NULL 1–120（入队 `"QUEUED"`、认领 `"CLAIMED"`、失败**保留最后阶段** JOBS.md:16）｜PK`(workspace_id,id)`｜FK`(workspace_id,retry_of)→jobs(workspace_id,id)`（跨工作区 `retry_of` 由 DB 直接拒）｜索引 `jobs_ready(state,created_at,workspace_id,id)` 只服务 T1 认领与容量计数（`listJobs` 的 `created_at DESC` 走反向扫描）。
- `artifacts` 行口径：PK`(workspace_id,id)`｜`UNIQUE(workspace_id,kind,sha256)`＝内容去重｜`relative_path` **全表 UNIQUE**、相对 `<data_dir>`、禁绝对路径（OPERATIONS.md:11「制品路径使用受控目录和 ID 解析」）｜`sha256` 长度 64｜`byte_size>=0`｜`created_at` NOT NULL。`idempotency` 行口径：PK`(scope_key=workspace_id, actor_id, operation ∈ {cancelJob,retryJob}, idem_key)`｜`request_digest = sha256(canonical_json({operation,workspace_id,job_id,if_match}))`(64)｜`response_status` + `response_json = {"headers":{"ETag":…,"Location":…},"body":<Job dump>}`（重放必须含头逐字节相同；若与 M0-02 `IdempotencyGuard` 落地结构不符，以落地为准并回报，N6）。`audit` 行口径：PK`(workspace_id,sequence)`、`sequence` 在**同一 `BEGIN IMMEDIATE` 内**取 `MAX(sequence)+1`（事务外取必撞 PK）｜`action ∈ {JOB_CANCEL_REQUESTED(T2/T4), JOB_CANCELLED(T8), JOB_RETRIED(T9)}`｜`target_kind="job"`、`target_id=<job_id>`｜`outcome ∈ {ACCEPTED,DENIED,FAILED}`（被拒的取消/重试也写 `DENIED`，与状态变更同事务）｜`previous_digest`/`digest` 哈希链由 M0-02 `application/audit.py::AuditWriter` 维护（只 import）。
- 常量与运行参数（全部经 `AppConfig` 可注入，测试用小值；禁 `sleep`、禁系统当前时间）：`LEASE_TTL_SECONDS=30`、`RENEW_INTERVAL_SECONDS=5`（JOBS.md:13「每 5 秒续租，租约到期为当前时间加 30 秒」）、`JOB_PENDING_LIMIT=10`、`JOB_CAPACITY_RETRY_AFTER_SECONDS=3`（JOBS.md:5,7）、`WORKER_HEARTBEAT_TTL_SECONDS=15`（ADR-005 §2.3）、`TMP_STALE_SECONDS=3600`。**心跳 TTL(15) 与 lease TTL(30) 是两个不同对象、不得混用**（同 ADR-005 对令牌 60s／会话 3600s 的口径）：健康先转 `OFFLINE`、租约后失效，顺序不得颠倒。M0-04 无金额／比率字段 → **任何位置禁 `float`**；持久层时刻一律 UTC ISO-8601（`Clock.now()` 注入），`TZ_SHANGHAI=Asia/Shanghai` 仅用于证据时间戳投影。

## 4. 事务边界（`BEGIN IMMEDIATE` 短事务；SQLite only，禁外部队列／broker）
- 连接：`infra/db/engine.py::make_engine()`（M0-02 冻结，内含 `PRAGMAS`＝`foreign_keys=ON`、`busy_timeout=5000`、`journal_mode=DELETE`，OPERATIONS.md:18）→ `engine.connect().execution_options(isolation_level="AUTOCOMMIT")`，由 `worker/store.py::immediate(conn)` 上下文管理器显式发 `BEGIN IMMEDIATE`／`COMMIT`、异常 `ROLLBACK`。**库路径一律 import `campaignlab.infra.db.paths`（ADR-005 §2.4 裁定 2 单一来源硬约束），M0-04 任何文件禁自行拼 `<data_dir>/state/campaignlab.db`、禁复制优先级链**；连接短时持有、不跨线程（PYTHON.md:5），每个事务一条新连接。
- 8 个短事务（禁嵌套、禁在事务内做重 I/O）：TX1 `claim_next`(T1)｜TX2 `renew`(T3)｜TX3 `request_cancel`(T2/T4)｜TX4 `confirm_cancel`(T8 执行确认)｜TX5 `succeed`(T5)｜TX6 `fail`(T6)｜TX7 `reap_expired`(T7 + T8 到期)｜TX8 `enqueue`/`retry`(T9)。事务号即 S2 的函数边界，一函数一事务，禁一函数跨两事务。
- 统一并发守卫：所有状态写都是**单条带谓词的 UPDATE**（API 侧谓词含 `revision=?`，worker 侧谓词含 `attempt=? AND lease_token=?`），`rowcount==1` 才算成功；`rowcount==0` → 回滚并抛领域错（API 侧 → 409 `STATE_CONFLICT`／412 `REVISION_CONFLICT`；worker 侧 → `LeaseLost`，静默放弃本次尝试）。**禁 SELECT-then-UPDATE 的无谓词写法**——`BEGIN IMMEDIATE` 串行化写者 ＋ 谓词 UPDATE 使败者 `rowcount=0`，是「两次认领只有一个成功」「失效租约不能提交」「终态唯一」「先提交者定终态」的唯一机器保证。
- 取消与完成争用（JOBS.md:23「若取消与完成争用，先成功提交的合法状态决定结果」）：TX4 与 TX5 的前态集合**都含** `CANCEL_REQUESTED`，谁先 `COMMIT` 谁定终态；败者 `rowcount=0` → 不得覆写、不得重试成第二终态，只记结构化日志。TX5 败者已 `os.replace` 的制品即成「未引用制品」，交 §5 `sweep_unreferenced` 回收（JOBS.md:23「旧尝试结果登记失败时其制品视为未引用」）。
- 事务内允许的唯一文件操作：TX5 里一次 `os.replace()`（同文件系统、O(1) 元数据操作）。摘要计算、临时件写入、源文件读取、DuckDB 计算一律在事务**外**（PYTHON.md:6「HTTP 进程只运行有界计算」）。
- 中断恢复：进程启动即 `recover(now)` → TX7；测试用 `FixedClock(step=timedelta(seconds=…))` 把时钟推过 `lease_until`，**禁 `sleep` 固定时长、禁 `datetime.now()` 出现在 `worker/**`**（唯一例外是 M0-02 已冻结的 `clock.py::SystemClock`）。轮询等待用可注入 `sleeper: Callable[[float], None]`（默认 `time.sleep`，测试传记录型假函数）。

## 5. 原子制品（`src/campaignlab/infra/artifacts.py`，public_frozen）
- 目录布局（全部落在 `<data_dir>` 内，OPERATIONS.md:17 七子目录）：**独立尝试目录** `<data_dir>/tmp/jobs/<workspace_id>/<job_id>/<attempt>/`（`attempt` 入路径 → 并发尝试互不覆写）；终态目录 `<data_dir>/results/JOB_RESULT/<workspace_id>/<sha256[:2]>/<sha256>`（**内容寻址** → 同摘要必同路径，这是「提交失败复用同摘要文件」的物理基础）。

AND kind=? AND sha256=?` **回读权威 id**（冲突时既有行的 id 胜出，`result_ref.id` 必须取回读值，**禁用刚生成的 id**）。
- 提交失败复用：`commit()` 必须幂等 —— 若 `final_path` 已存在且 sha256/byte_size 相符则跳过 `os.replace` 直接登记；TX5 回滚后重试命中同一摘要文件（JOBS.md:25「事务提交失败允许重试并复用同摘要文件」）。
