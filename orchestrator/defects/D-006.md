# D-006 · 分母口径未定义：`ruff format` 计数含 Markdown，历史值 35 不可复现

- 严重度：MINOR（治理/度量口径，不影响产品行为）
- 状态：FIXED_PENDING_Q
- 发现时间：2026-11-12T22:50:51+08:00
- 发现者：编排器（第 3 次接管后按手册 15.3 全表重跑）
- 证据：`evidence/monthly/M0-P01/run-04/commands.md` 第 2.1 节

## 1. 现象

`state.json.resume.self_check_gates_rc0.counts.ruff_formatted_files` 记为 35，本次实测为 37；
而按 `pyproject.toml` 的 `extend-exclude = ["spec","prototype","web","node_modules"]`，
作用域内 `.py` 只有 6 个（`ruff format --check scripts src tests` -> `6 files already formatted`）。
35 与 37 都无法由「Python 文件数」解释，历史值也未记录构成与命令，属手册 15.4 第 6 条所禁止的
「分母不可复现」。

## 2. 根因

`ruff 0.17.4` 的 `format` 作用域**包含 `.md` 文件**，因此 `ruff format --check .` 的
`N files already formatted` 是「Python + Markdown」的混合计数，不是 Python 分母。
探针实测：`docs/` 内新增 1 个 `.py` 使计数 8 -> 9；新增 `.txt` 或无扩展名文件计数不变；
`docs/` 实有 8 个 `.md` + 1 个 `.pptx` + 1 个 `.docx`，报 8。

## 3. 定量核算

- 逐目录：`contracts 1` + `docs 8` + `evidence 10` + `orchestrator 11` + `scripts 3` + `src 1` + `tests 2` + 根 `README.md 1` = **37**
- 构成：**37 = 6 个作用域内 `.py` + 31 个作用域内 `.md`**
- 复现命令：
  - `git ls-files '*.py' | grep -vE '^(spec|prototype|web)/' | wc -l` -> 6
  - `git ls-files -z '*.md' | tr '\0' '\n' | grep -vE '^\"?(spec|prototype|web)/' | wc -l` -> 31
- 排除生效验证：把 `x = 1` 探针写入 `spec/`、`prototype/`、`.venv/`、`web/`，计数均不变。

## 4. 修复（本次治理提交内完成）

1. `counts.ruff_formatted_files` 改为实测 37，并新增 `ruff_formatted_files_composition`
   （`cmd` / `total` / `in_scope_py` / `in_scope_md` / 两条复现命令 / `why_md_counted` / `exclusions_verified` / `historical_value`）。
2. 新增 `counts.ruff_lint_scope_files = 6`（`ruff check . --show-files`），把「Python 质量门分母」与
   「format 混合计数」分开，避免后续实例再次误读。
3. 手册 15.4 增补条款：任何计数型分母必须同时记录**构成与可复跑命令**；口径含非目标文件时必须显式说明。

## 5. 影响面与回归

- 不影响 G1–G14 任何门禁的 rc 判定（全部 rc==expected）。
- 不影响 `spec/` 只读基线（`git status --porcelain spec/` = 0）。
- Q 复核时请以 `ruff_lint_scope_files=6` 作为 Python 分母，以 `ruff_formatted_files=37`（含 md）作为
  `ruff format --check .` 的输出分母，两者不可互换。
