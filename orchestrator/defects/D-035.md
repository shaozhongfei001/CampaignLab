## 1. 现象（实测，非转录）

命令：`uv run --no-sync mypy`
配置：`pyproject.toml` 的 `[tool.mypy]` → `python_version = "3.14"`、`strict = true`、`mypy_path = "src"`、`files = ["src", "tests", "scripts"]`、`exclude = "^(spec|prototype|web|[.]venv)/"`


## 2. 引入点与根因

- **引入提交**：`57b6db5` —— `test(M0-02/S4): 契约测试参数化 51 例 + FU-12 正向覆盖 + 立 D-033（S lane / Round 8）`，该提交新增 `tests/api/conftest.py`（193 行）。
- **既有同名文件**：`tests/integration/bootstrap/conftest.py`（3681 B，由 `08d0b5c` / M0-02-S2 引入）。
- **根因**：`tests/**` 各级目录**无 `__init__.py`**（全仓仅 7 个 `__init__.py`，均在 `src/campaignlab/**`）。mypy 在无包标记时以「相对 rootdir 的最短唯一路径」推断模块名，两个 `conftest.py` 同时被推断为顶层模块 `conftest` → 重复模块名，属**阻塞级错误**（blocking error），mypy 立即停止，不再检查任何文件。
- 在 `57b6db5` 之前仓内只有一个 `conftest.py`，故 G9 一直为绿（上次全表实测 `Success: no issues found in 16 source files`，2026-11-13T04:58:57+08:00）。

## 3. 影响面（关键）

1. **G9 红灯**：全表门禁 15 项中唯一 MISMATCH 项。
2. **覆盖面归零**：`errors prevented further checking` 意味着 `src` + `tests` + `scripts` **三棵树全部未被类型检查**。`strict = true` 的机器保障自 `57b6db5` 起实际失效，期间入库的 `src/campaignlab/worker/**`（1723 行）、`infra/db/repositories.py`（+431）等**均未经全树 mypy 复核**（当时仅做过路径限定 mypy：Volta 11 source files rc=0、Bohr 3 source files rc=0）。
3. **counts 不可测**：`resume.self_check_gates_rc0.counts.mypy_source_files` 本次**无法实测**（mypy 未产出 `Success: no issues found in N source files`）。按「禁估算」纪律保留上次可测值并加注，不得填新数。
4. **不影响的门**：G7 ruff check rc=0、G8 ruff format 176 files rc=0、G10 pytest **350 passed** rc=0、G5/G6 契约门 rc=0、G3 前端基线 8/8、G11 字节级复现 4/4、G12 PACKAGE 6/6、G14 doctor HEALTHY。即**运行期行为与测试全绿，仅静态类型门失效**。

## 4. 编排器责任（自我更正 R8-4）

`57b6db5` 入库时，编排器只复跑了**路径限定**门禁（`ruff format --check` 3 files、`ruff check`、`mypy` 3 source files、`pytest tests/api` 51 passed、近邻 55 passed）即判定复验通过并提交推送。路径限定 mypy 只看 `tests/api/**`，**不会触发跨目录重复模块名检测**，故漏检。
教训固化：凡新增 `conftest.py`、或与既有文件**同 basename** 的新文件入库，复验必须跑一次全树 mypy（`uv run --no-sync mypy`），不得以路径限定 mypy 替代。已写入 `resume.gate_measurement_caliber`。

## 5. 修法（三选一，推荐 B）

| 选项 | 做法 | 评估 |
|---|---|---|
| **B（推荐）** | `pyproject.toml` 的 `[tool.mypy]` 增 `explicit_package_bases = true`（必要时并 `namespace_packages = true`），使每个文件以「相对 root 的路径」为模块名（`tests.api.conftest` / `tests.integration.bootstrap.conftest`） | **不动任何测试文件**，覆盖面不减，改动面 1-2 行配置；须实测确认 `mypy_path = "src"` 与 `files` 列表在 explicit 模式下的 root 推断仍正确（root 为 cwd） |
| A（备选） | 在 `tests/`、`tests/api/`、`tests/integration/`、`tests/integration/bootstrap/`、`tests/unit/` 各加 `__init__.py` | 同样解冲突；但会把 tests 变成包，须复跑 `pytest -q` 确认 prepend import-mode 无回归（350 passed 不得下降），且新增 5 个文件会推高 counts |
| C（**禁止**） | `exclude` 掉 `conftest.py` 或其中一处 | 削弱覆盖面，违反「禁降门禁」纪律，不予考虑 |
