# UI-09 指标字典与口径证据

路由 `/w/:workspace_id/definitions`。导航为「数据与口径」。适用角色为指标负责人、运营。需求编号 FR-09。

核对同名率的分母、聚合和数据来源。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 上方 | 固定快照与口径版本 |
| 全宽表 | 指标、单位、公式、分子、分母、聚合方式、来源 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 指标 | ID、显示名、单位、公式、版本 | Definition |
| 证据 | 来源编号、位置、摘要及授权节选 | Evidence |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 浏览与按名称查找 | listSnapshots, listDefinitions | 快照选定后按字典分页 |
| 核查源证据 | getEvidence | 打开抽屉或复制编号 |

## 页面状态与边界

- 公式按服务端字典显示。分母或定义缺失时展示来源待补。当前合成示例有效触达率 15%，最后一层率 50%，分母不同。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
