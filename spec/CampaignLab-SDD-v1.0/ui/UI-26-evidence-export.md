# UI-26 证据、审计与导出

路由 `/w/:workspace_id/evidence`。导航为「作业与证据」。适用角色为审核者、本机操作员。需求编号 FR-26。

检索业务来源、确认轨迹和导出记录，供他人按原条件复核。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 页签 | 证据、审计、已导出 |
| 全宽列表 | 类型、来源、位置、摘要、对象、时间 |
| 右抽屉 | 节选、访问范围和复制编号 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 证据 | 类型、来源编号、定位、节选和内容摘要 | Evidence |
| 导出 | 对象、类型、用途、文件摘要和大小 | ExportCreate/Export |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 查找与登记证据 | listEvidence, getEvidence, registerEvidence, listAudit | 手工来源输入文本和引用，摘要由服务端生成 |
| 生成并下载 | listExports, createExport, getExport, downloadExport | 预览导出范围，待作业完成后下载 |

## 页面状态与边界

- 不具备读取范围的证据不显示。默认按授权字段导出。报告、案例和来源可用摘要复核。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
