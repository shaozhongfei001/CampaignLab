# UI-03 活动详情与版本回执

路由 `/w/:workspace_id/activities/:activity_id`。导航为「活动与规则」。适用角色为活动策划、验收人员。需求编号 FR-03。

查看来源活动、有效绑定与规则版本，在预发审阅通过后登记行内回执。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 摘要区 | 左 8 列活动名称、来源和当前验证版本，右 4 列准备状态 |
| 下方页签 | 绑定、规则版本、预发与回执 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 绑定表 | 策略编号、源规则版本、有效起止、证据编号 | Binding |
| 规则表 | 版本名、状态、摘要、确认时间 | RuleVersion |
| 回执表 | 来源系统、行内版本、发布时间、预发批次 | Receipt |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 更新活动或绑定 | getActivity, updateActivity, getEvidence | 保存时提交当前修订号，绑定起止与策略证据均有效 |
| 新建或从版本复制 | listRules, createRule | 草稿以 parent_rule_id 记录来源，跳到规则页 |
| 登记并查阅回执 | listPreflights, recordReceipt, getReceipt | 仅展示已审阅且一致的预发，提交后在同一活动列出 |

## 页面状态与边界

- 绑定缺失时显示活动复盘待补。已归档活动只读。预发缺项、版本过期或仍有差异时显示对应原因，回执动作由服务端核验。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
