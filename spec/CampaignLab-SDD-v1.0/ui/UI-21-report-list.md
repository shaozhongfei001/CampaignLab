# UI-21 报告列表与新建

路由 `/w/:workspace_id/reports`。导航为「报告与改进」。适用角色为运营、报告审核者。需求编号 FR-21。

按范围查找报告与修订版本，从已计算结果生成七段式复盘。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 头部 | 状态、关键词、生成报告 |
| 表格 | 标题、类型、期间、快照、状态、签认人、版本链 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 生成 | 复盘编号、诊断、专题问题、报告类型和标题 | ReportCreate |
| 行项 | 报告状态、原版本、创建与签认时间 | Report |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 筛选并进入报告 | listReports, getReport | 保留列表状态 |
| 生成报告 | getReview, createReport, getJob | 使用选定复盘结果，成功后进入报告详情 |

## 页面状态与边界

- 缺复盘结果引导先计算。缺数可以创建取数清单。部分可比允许形成草稿并标注共同范围。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
