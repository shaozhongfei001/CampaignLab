# UI-18 异常诊断与贡献拆解

路由 `/w/:workspace_id/diagnosis`。导航为「策略复盘」。适用角色为运营、指标负责人。需求编号 FR-18。

用有证据的异常规则定位影响量，提出可分派、可验证的假设。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 顶部 | 固定复盘范围，右侧阈值版本和规则筛选 |
| 中部 | 全宽异常清单，随后两列量率和维度 |
| 下部 | 六个月趋势、可核查的业务假设、登记改进项 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 异常 | 对象、指标、本期、基准、阈值、影响、证据 | Diagnosis.alerts |
| 拆解 | 依次替换因素、维度值、贡献和余量 | Diagnosis.funnel/dimension_rows/residual |
| 阈值 | 期间、同组、自身、层间和结构变化 | ThresholdCreate |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 重算诊断 | getReview, listThresholds, runDiagnosis, getJob, getDiagnosis | 锁定 review_id、阈值、指标和方向，结果显示可比边界 |
| 新建阈值版本 | createThreshold | 字段标清 %、σ 和百分点，保存后重新计算 |
| 创建改进项 | createAction, getEvidence | 选择假设，填写责任、日期和验证方式后打开改进详情 |

## 页面状态与边界

- 部分可比可在共同子集显示拆解，异常规则需符合其完整比较条件。缺足够历史时趋势用空点。原因以统计线索呈现。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
