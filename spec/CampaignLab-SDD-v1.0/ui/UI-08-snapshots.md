# UI-08 数据快照与更正

路由 `/w/:workspace_id/snapshots`。导航为「数据与口径」。适用角色为指标负责人、审核者。需求编号 FR-08。

按银行和版本核查来源、覆盖及更正，保证旧报告可重现。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 左 4 列 | 快照列表，默认按创建倒序 |
| 右 8 列 | 来源、覆盖、字典、批次和更正历史 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 摘要 | 银行、标签、切片数、映射、快照摘要、上游批次、来源活动 | Snapshot |
| 覆盖 | 月份、渠道、截止、定义、语义、采集状态 | Coverage |
| 补数 | 切片、金额字段、分单位的新值及证据 | SnapshotCorrection |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 选定快照 | listSnapshots, getSnapshot, getEvidence | 查看当前覆盖，并可进入字典与复盘 |
| 登记金额更正 | registerEvidence, correctSnapshot, getJob | 预览原值与新值，确认理由后创建新快照 |

## 页面状态与边界

- 无快照时引导导入。更正只针对指定已发布源行和允许的金额字段。原快照可选。缺渠道或定义更新从导入入口处理。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
