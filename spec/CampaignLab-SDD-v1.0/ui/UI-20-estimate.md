# UI-20 接触转化情景试算

路由 `/w/:workspace_id/estimate`。导航为「仿真与验收」。适用角色为渠道运营。需求编号 FR-20。

用汇总数据估算假设转化率对应人数和差值。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 上方 | 固定复盘、快照、期间和渠道 |
| 两列 | 左 5 列公式及转化假设，右 7 列原值、试算、差值 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 输入 | 复盘结果、接触层间率 0 到 100% | EstimateCreate，传输转 0 到 1 |
| 结果 | 已执行、固定末层率、原有效、试算精确值和取整人数 | Estimate |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 运行估算 | getReview, computeEstimate | 输入 45% 得 1,944，比 1,728 多 216，标明条件试算 |
| 核对来源 | getEvidence | 展开分母与范围，可转案例库进行逐笔验证 |

## 页面状态与边界

- 固定层率或已执行缺失时展示所需数据。观察与试算来自不同证据类型。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
