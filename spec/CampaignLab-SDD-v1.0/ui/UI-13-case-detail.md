# UI-13 案例输入、实测与预期

路由 `/w/:workspace_id/cases/:case_id`。导航为「仿真与验收」。适用角色为业务审核者、验收人员。需求编号 FR-13。

保留可复跑的事件、初始状态、来源、实测与人工预期。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 左 8 列 | 客户范围、初始状态、事件序列 |
| 右 4 列 | 期望和原实际、来源、摘要与确认 |
| 底部 | 提交确认、复制为新修订、加入运行 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 事件 | 序号、类型、时刻、订单或策略、金额/预约 | CaseInput |
| 结果 | 赢家、占用次数、预算、订单券状态 | Outcome |
| 关联 | 原规则版本、动作和证据 | Case |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 保存输入及观察 | getCase, updateCase, registerEvidence | 显示字段错误、来源和当前修订 |
| 确认或复制 | confirmCase, createCase | 确认版本需要摘要。复制使用 parent_case_id |
| 进入运行 | createRun | 选择当前活动确认的规则和当前案例，带至运行结果 |

## 页面状态与边界

- 历史模式需要实测、原规则和来源。确认为不可变。缺逐笔历史输入时显示取数清单并链接情景估算。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
