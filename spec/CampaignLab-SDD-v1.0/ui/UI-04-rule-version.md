# UI-04 规则版本编辑与对比

路由 `/w/:workspace_id/activities/:activity_id/rules/:rule_id`。导航为「活动与规则」。适用角色为活动策划、审核者。需求编号 FR-04。

把来源条款绑定到可执行字段，核对版本差异并形成固定版本。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 左 7 列 | 规则模板表单。选择满额赠券或远程回拨，按模板显示适用字段 |
| 右 5 列 | 原条款、待确认项、版本对比和证据 |
| 底部 | 草稿保存、规则检查、确认版本 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 赠券 | 起止时间、新客天数、门槛、券面额、次数、预算、叠加、退款 | CouponRule |
| 回拨 | 渠道、优先方式、单日上限 | CallbackRule |
| 条款 | 键、来源、业务决定、状态、证据 | Term |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 编辑并保存 | getRule, updateRule, registerEvidence | 仅草稿可编辑，表单显示元同时准确换算分 |
| 查看差异 | compareRules | 选择同活动同模板比较版本，显示字段前后值和需复跑案例 |
| 确认版本 | confirmRule, checkRule | 确认当前摘要和说明，完成后在活动显示新候选版本 |

## 页面状态与边界

- 时间起止、金额、条款缺失显示到具体字段。确认后只读，修改入口返回活动复制新草稿。412 让用户比较服务器版本与本地草稿。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
