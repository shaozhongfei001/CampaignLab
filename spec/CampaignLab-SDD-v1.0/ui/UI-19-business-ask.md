# UI-19 业务问答与专题入口

路由 `/w/:workspace_id/ask`。导航为「策略复盘」。适用角色为分行运营、指标负责人。需求编号 FR-19。

以业务问题查数、查口径、判断异常或发起专题，并能检查系统理解的范围。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 上方 | 问题输入、常用示例和解析按钮 |
| 左 5 列 | 已解析范围及可编辑条件 |
| 右 7 列 | 数值、字典、异常、拆解或专题入口 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 问题 | 300 字内问题和当前上下文 | QuestionInput |
| 计划 | 意图、期间、机构、指标、条件、方向、分组 | QuestionPlan |
| 结果 | 来源、当前值、比较、证据和专题状态 | QuestionResult |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 解析 | interpretQuestion | 缺机构、指标或策略时展示澄清字段，不自动执行 |
| 核对后计算 | listThresholds, executeQuestion, getJob, getQuestion | 题述值供核查。显式执行后按计划计算 |
| 生成专题 | createReport, getEvidence | 仅已执行 REPORT 且结果可关联同范围 review_id 时启用 |

## 页面状态与边界

- Q03、Q04 要求补充。R08 命中两分行。R54 可生成客户经理专项。语句不明确时可切结构化输入。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
