# UI-06 数据导入任务

路由 `/w/:workspace_id/imports`。导航为「数据与口径」。适用角色为指标与数据负责人。需求编号 FR-06。

导入合成宽表、长表或授权导出，定位失败批次。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 全宽工具栏 | 银行、格式、状态和新建导入 |
| 全宽表格 | 任务、版本、表数、状态、快照与更新时间 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 首次上传 | 数据文件、格式、表名、银行、快照版本、更正来源 | Upload multipart |
| 任务表 | 编号、银行、映射、校验状态、快照 | Import |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 查看任务 | listImports, getImport | 点行进入映射与校验 |
| 上传并继续 | createImport | 入口接受 CSV/JSON，显示文件限制、原始摘要及被识别的合成文件 |

## 页面状态与边界

- 上传失败保留格式和字段，提示重复版本、文件大小或无法解析。相同文件重复提交保持原任务。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
