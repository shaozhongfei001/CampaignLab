# UI-23 改进项列表

路由 `/w/:workspace_id/actions`。导航为「报告与改进」。适用角色为运营、行动责任人。需求编号 FR-23。

追踪诊断形成的动作、责任人、期限和复核进展。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 工具栏 | 状态和关键字、从复盘新建 |
| 全宽表 | 责任、到期、30/90 天、状态、待复核标记 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 行项 | 标题、来源异常、责任人、日期、验证说明和状态 | Action |
| 新建 | 当前复盘、假设、动作、负责人、期限 | ActionCreate |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 查看列表 | listActions, getAction | 点行进入详情，已闭环项可查看 |
| 新建改进 | getReview, createAction | 绑定源复盘，填齐验证方式后打开详情 |

## 页面状态与边界

- 空列表引导从异常登记。待复核项突出旧版和当前数据的证据差异。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
