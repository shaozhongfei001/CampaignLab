# UI-07 映射配置与发布

路由 `/w/:workspace_id/imports/:import_id`。导航为「数据与口径」。适用角色为指标与数据负责人。需求编号 FR-07。

核对来源字段、单位、阶段指标及元数据，校验并发布可分析快照。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 上方步骤条 | 文件 → 映射 → 校验 → 发布 |
| 左 7 列 | 表形、维度、阶段、金额和代码映射网格 |
| 右 5 列 | 文件摘要、问题列表、发布操作 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 文件 | 表名、大小、哈希、数据来源 | Import.files |
| 映射 | 映射编号、宽/长、表名、长表连接列、计数、币值单位、去重模式 | SourceMapping |
| 问题 | 等级、表/行/列、原因、修正建议 | Import.issues |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 附加表文件 | attachImportFile | 在可编辑状态上传后旧验证失效 |
| 保存映射 | getImport, configureImport | 校验必填字段和单位，使用 If-Match |
| 校验 | validateImport, getJob | 等作业完成后刷新导入状态并定位问题 |
| 发布快照 | publishImport, getSnapshot | 提交当前 validation_digest 与说明，成功后进入快照 |

## 页面状态与边界

- VALIDATING/PUBLISHING 期间保护编辑。INVALID 显示首个错误及全部问题。发布失败留可重试状态。已发布文件及映射只读。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
