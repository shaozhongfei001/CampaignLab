# UI-14 运行中心与批量复跑

路由 `/w/:workspace_id/runs`。导航为「仿真与验收」。适用角色为验收人员。需求编号 FR-14。

选择同活动的确认案例和版本，启动单例或批量仿真并回查结果。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 上方 | 活动、原规则、候选规则与快照 |
| 全宽 | 案例多选与运行列表，底部主按钮运行 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 运行输入 | 已确认案例 1 至 1000、原版本、候选版本、可选快照 | RunCreate |
| 历史 | 运行编号、两版、案例数、状态、摘要 | Run |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 选择输入并运行 | listRules, listCases, createRun, getJob | 选择一条即单例，多个为批次。核对摘要后提交 |
| 查看历史结果 | listRuns, getRun | 默认最近运行在前，点行打开结果 |

## 页面状态与边界

- 混用模板、跨活动和草稿阻止提交。作业中断后从作业中心按原输入重试。切换规则先复查影响案例。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
