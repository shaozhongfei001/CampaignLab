# UI-02 活动列表

路由 `/w/:workspace_id/activities`。导航为「活动与规则」。适用角色为活动策划、运营。需求编号 FR-02。

快速定位活动验证副本、新建本地活动或按行内编号继续验证。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 标题行 | 活动总览，右侧新建活动 |
| 全宽列表 | 编号、活动、来源银行、行内编号、当前仿真版本、状态 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 过滤 | 名称或编号、状态 | listActivities q/status |
| 新建 | 名称、银行编号、行内活动编号、说明 | ActivityCreate |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 搜索与进入活动 | listActivities, getActivity | 按游标更新列表，行点击进入活动详情 |
| 新建活动 | createActivity | 来源银行与行内编号成对填写，创建成功进入详情 |

## 页面状态与边界

- 空列表提供创建。已归档活动可检索和查看。相同银行行内活动编号重复显示冲突并定位既有记录。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
