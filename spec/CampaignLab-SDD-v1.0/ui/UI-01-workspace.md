# UI-01 工作区与首次进入

路由 `/`。导航为「入口」。适用角色为本机操作员。需求编号 FR-01。

换取本机会话，创建工作区并选择数据用途，进入两条业务流程。

## 页面结构

| 区域 | 布局与内容 |
|---|---|
| 顶栏 | 状态、当前操作者、最近工作区 |
| 12列主卡 | 左 8 列工作区列表，右 4 列两条首跑路线。窄屏路线置于列表下方 |

使用 [公共页面规范](COMMON.md) 的 12 列、状态、键盘与证据抽屉。下表以服务端模型为数据来源。

## 字段和绑定

| 区域 | 字段 | 接口模型 |
|---|---|---|
| 列表 | 名称、数据用途、创建时间 | Workspace.name/source_class/created_at |
| 创建 | 名称必填，选择合成或授权脱敏，后者填写授权依据 | WorkspaceCreate |

## 操作、接口与反馈

| 动作 | operationId | 提交和反馈 |
|---|---|---|
| 进入本机工作台 | exchangeSession, getSession | 入口令牌仅在首次使用，随后按会话检查。成功后加载列表 |
| 刷新工作区 | getHealth, listWorkspaces | 服务可用时取列表，worker 离线时显示作业受限 |
| 新建工作区 | createWorkspace | 成功后进入所选工作区的活动页 |

## 页面状态与边界

- 无工作区时突出创建。授权脱敏须在操作记录填来源授权，工作区类型创建后固定。切换后清除上一个工作区的草稿范围和轮询。
- 首载、空结果、失败、版本变化和权限状态采用公共页面规范。详情和制品以当前工作区校验结果为准。
