# 工作台公共页面规范

## 布局和可见层级

桌面参考画布 1440×900，左导航 216px，顶栏 56px，主内容左右各 24px，内容区最高宽 1440px 居中。主区使用 12 列等宽栅格，列间距 16px，卡片间距 16px。标题行高 32px，正文基准 14px，表格行高 40px，密集数据表 36px，统计标签 13px。字体首选本机 Noto Sans CJK SC，后备系统无衬线，金额和时间启用等宽数字。组件圆角 8px，边框 1px，按钮高 36px，主要动作每区最多一个。边距使用 4、8、12、16、24、32px。信息依次为「当前对象与范围 → 关键操作 → 结果和证据」。

| 令牌 | 值 | 用途 |
|---|---|---|
| 背景 / 卡面 / 分割 | #F3F6FA / #FFFFFF / #DCE4ED | 稳定内容层 |
| 导航 / 正文 / 次要 | #14243B / #172942 / #4F6177 | 导航与文字层级 |
| 主动作 / 聚焦 | #2456C8 / #2456C8 | 按钮、链接、2px 焦点线 |
| 成功 / 警示 / 错误 | #176A48 / #875900 / #A53232 | 同时配文字和图标 |
| 蓝底提示 / 警示背景 | #F0F5FF / #FFF4D8 | 范围、待补和局部提示 |

≤1100px 导航折至 64px 图标列并提供标签提示，左右内边距 16px，双列可折叠；≤800px 导航改抽屉，主内容单列，数据表在自身区域横滚。证据抽屉桌面 480px，窄屏全宽。确认对话框宽 520px，提供摘要、影响、取消及主按钮。所有滚动容器保留键盘焦点和表头，冻结首列仅用于宽表。图表有可切换的等义表格。

## 导航和输入范围

`/` 为本机工作区。工作区内一级导航为活动与规则、数据与口径、仿真与验收、策略复盘、报告与改进、作业与证据。页面内链接携带 workspace_id 与资源 ID。子页返回列表保留筛选、排序及滚动位置。404 显示当前工作区的返回入口。工作区切换清理本地页面临时查询、轮询及失效选择。

范围条位于页头下方。基本项为快照、月份、机构、渠道和比较基准。展开高级项提供截止、分组、支行、策略来源、策略、活动、部署客群或月末标签。URL 保存非敏感资源 ID 和受控筛选字段，问题原文及客户资料留在服务请求。可复盘链接优先使用固定的 review_id 或其他结果资源 ID。变更筛选先预览，再点「计算」。结果返回显示本期、基准、快照、口径、覆盖和摘要。当前页面始终区分所选范围和上次计算范围。

## 共享状态与操作

| 场景 | 行为 |
|---|---|
| 首载 | 主区骨架对应标题、表头和卡片位置。保留导航 |
| 无记录 | 指明当前筛选，提供创建、导入或清空筛选入口 |
| 排队或计算 | 显示作业号、阶段和进度，允许到作业中心。上次结果可见且有「上一结果」标识 |
| 部分可比 / 待补 | 原值仍显示，差值按共同子集或留空。提供原因、缺项和导出入口 |
| 校验失败 | 错误摘要跳转字段，字段标注语义。保留输入 |
| 过期 | 412 或候选失效时保留本地输入，显示新旧版本和重新获取或复跑入口 |
| 会话 / 权限 | 会话过期引导重开本机入口。越权对象按不可见处理。业务按钮与服务端前置条件一致 |
| 确认动作 | 有不可变记录产生时展示人、对象、版本、备注。确认后只提交一次，重试沿原幂等键 |
| 明细和证据 | 抽屉显示定位、来源、版本、截止、公式、分子分母、摘要。可复制证据编号和返回 |
| 数字 | 缺值显示 — 与原因。比率小数转百分数，率差转百分点，金额分转元，负余额增量保留 |

表单绑定输入 Schema。相同任务请求收到 202 后使用 GET 作业，成功再取结果。错误显示 request_id。列表默认 25 行，更多数据由服务器游标加载。图标按钮须有名称，抽屉 Esc 可关闭并返回触发焦点，表格排序支持键盘。焦点和读屏提示以 WCAG 2.2 AA 为验收目标。所有业务页面使用这些规则及各页专属状态。
