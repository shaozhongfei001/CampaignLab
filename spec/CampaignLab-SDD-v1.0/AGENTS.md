# CampaignLab 本机实施约定

## 工作目标

依据本包开发一套本地可运行的 CampaignLab，交付满额赠券和远程回拨两条端到端业务流程。范围、功能优先级与运行模式见 [ADR-001](decisions/ADR-001-approved-scope.md)。逐页交互见 [UI 索引](ui/INDEX.md)。先通过包校验，再从 M0 开始实施。

## 变更权限

项目负责人裁定业务规则、首版范围、数据权限和正式交付。技术负责人拆任务与收敛契约，独立 QA 复核实测证据。常规实现选择由开发角色在已确认范围内完成。涉及分母、状态、接口兼容、取数依据或资金模拟语义的变化，提交一个 ADR 和对应回归用例，并在收到业务裁定前继续可独立完成的任务。

保持每次提交可追踪。需求与验收编号复用 [追踪矩阵](product/TRACEABILITY.md)。任何新接口同时更新 OpenAPI、调用页面与测试。任何新业务状态同时更新状态契约、页面按钮权限、持久层约束与失败用例。

## 工作区与数据

在调用外部工具或处理真实文件前，按 [运行与保护](architecture/OPERATIONS.md) 核对授权范围。开发样例全部使用 `fixtures/`。行内发布、审批、发奖和触达由行内平台办理。应用写入本地仿真对象，接收允许的行内导出及回执。执行环境为单机 CPU，面向 localhost 浏览器。

## 完成条件

按 [交付计划](framework/DELIVERY.md) 逐阶段完成，记录命令、退出码、可查证的运行产物及剩余问题。包校验与开发自测分别报告，独立 QA 单列。系统运行就绪以产品实际启动、导入、复跑、重启恢复和浏览器验收为依据。
