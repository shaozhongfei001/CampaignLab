# ADR-002 首版实施约定

状态 `DESIGN_DEFINED`。以下细节由设计交接确定，开发者按此实现并用合成数据验证。

| 细节 | 约定 | 依据和回退 |
|---|---|---|
| 规则表达 | 两种类型化模板，固定字段和受控状态机 | 覆盖已确认两条流程，扩展字段由真实用例驱动。专有规则依预发证据对照 |
| 单机队列 | SQLite 短事务、单 worker、租约、固定输入和原子制品 | 初始吞吐按 M5 量测，竞争与恢复用 AC-029 |
| SQLite 日志 | 本机 DELETE 默认，busy timeout 5 秒 | 易备份、短写入。测得必要再评估 WAL，并明确运行库版本 |
| 前端分辨率 | 1440×900 为设计基准，验证 1024×768 和窄屏 | 兼顾业务高密度表格和键盘操作 |
| 数据表示 | 业务时区 Asia/Shanghai、人民币分、统计十进制字符串 | 固定演示精度和时间端点。新增币种或时区须补真实规则与对账 |
| 安装版本 | Python 3.14、Node 24 和依赖范围，M0 锁补丁版本 | 包提供版本约束和验收命令，实际构建锁随目标机器产生 |
| 自然问法 | 登记计划和受控词典 | 同输入可重复。扩展自然语言能力由正确率、可解释性和运行边界决定 |

软件发布、正式行内接入和产品商业证据由对应验证阶段确认。
