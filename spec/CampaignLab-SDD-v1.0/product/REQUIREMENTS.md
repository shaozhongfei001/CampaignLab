# 业务 功能与非功能需求

首版范围按 ADR-001。业务口径、公开证据、合成样例、待确认的真实证据通过追踪矩阵连接。

## 业务需求

| 编号 | 能力 | 页面覆盖 |
|---|---|---|
| BR-01 | 可操作的活动规则与来源 | UI-02 至 UI-05 |
| BR-02 | 可独立适配与复核的行内数据 | UI-06 至 UI-11 |
| BR-03 | 可复跑的案例、版本差异和预发验收 | UI-12 至 UI-16、UI-20 |
| BR-04 | 同范围的策略复盘、异常诊断与问答 | UI-17 至 UI-19 |
| BR-05 | 有依据的报告、改进和下期复核 | UI-21 至 UI-24 |
| BR-06 | 本机部署、作业、证据和权限 | UI-01、UI-25、UI-26 |

## 功能需求

| 编号 | 使用者 | 任务 | 页面契约 | 验收 |
|---|---|---|---|---|
| FR-01 | 本机操作员 | 换取本机会话，创建工作区并选择数据用途，进入两条业务流程。 | [UI-01](../ui/UI-01-workspace.md) | AC-001、AC-034 |
| FR-02 | 活动策划、运营 | 快速定位活动验证副本、新建本地活动或按行内编号继续验证。 | [UI-02](../ui/UI-02-activity-list.md) | AC-002、AC-032 |
| FR-03 | 活动策划、验收人员 | 查看来源活动、有效绑定与规则版本，在预发审阅通过后登记行内回执。 | [UI-03](../ui/UI-03-activity-detail.md) | AC-002、AC-003、AC-017 |
| FR-04 | 活动策划、审核者 | 把来源条款绑定到可执行字段，核对版本差异并形成固定版本。 | [UI-04](../ui/UI-04-rule-version.md) | AC-003、AC-004、AC-034 |
| FR-05 | 活动策划、验收人员 | 集中处理规则缺口、重复与冲突，选择建议的边界案例进行验证。 | [UI-05](../ui/UI-05-rule-check.md) | AC-004、AC-012 |
| FR-06 | 指标与数据负责人 | 导入合成宽表、长表或授权导出，定位失败批次。 | [UI-06](../ui/UI-06-import-list.md) | AC-005、AC-006 |
| FR-07 | 指标与数据负责人 | 核对来源字段、单位、阶段指标及元数据，校验并发布可分析快照。 | [UI-07](../ui/UI-07-import-detail.md) | AC-005、AC-006、AC-029 |
| FR-08 | 指标负责人、审核者 | 按银行和版本核查来源、覆盖及更正，保证旧报告可重现。 | [UI-08](../ui/UI-08-snapshots.md) | AC-007、AC-020、AC-026 |
| FR-09 | 指标负责人、运营 | 核对同名率的分母、聚合和数据来源。 | [UI-09](../ui/UI-09-metric-dictionary.md) | AC-008、AC-018 |
| FR-10 | 指标与数据负责人 | 在同口径范围核对甲乙指标，保留采集和定义差异。 | [UI-10](../ui/UI-10-bank-compare.md) | AC-009、AC-020 |
| FR-11 | 渠道运营、指标负责人 | 复核六渠道阶段条件与产能事件归属，了解多候选和未匹配原因。 | [UI-11](../ui/UI-11-channel-evidence.md) | AC-010、AC-011 |
| FR-12 | 活动策划、验收人员 | 按活动查找或新建案例，选择复跑输入和来源。 | [UI-12](../ui/UI-12-case-list.md) | AC-012、AC-034 |
| FR-13 | 业务审核者、验收人员 | 保留可复跑的事件、初始状态、来源、实测与人工预期。 | [UI-13](../ui/UI-13-case-detail.md) | AC-012、AC-013、AC-015 |
| FR-14 | 验收人员 | 选择同活动的确认案例和版本，启动单例或批量仿真并回查结果。 | [UI-14](../ui/UI-14-run-list.md) | AC-013、AC-029 |
| FR-15 | 活动策划、验收人员 | 理解哪个事件导致规则结果分歧，保存可移交的候选预期。 | [UI-15](../ui/UI-15-run-result.md) | AC-014、AC-015、AC-016、AC-030 |
| FR-16 | 验收人员、业务审核者 | 把行内预发的实际结果逐例对照冻结的预期并记录审阅。 | [UI-16](../ui/UI-16-preflight.md) | AC-016、AC-017 |
| FR-17 | 分行运营、渠道运营 | 核对参与度、五层漏斗和执行效果，识别最值得进一步核查的环节。 | [UI-17](../ui/UI-17-strategy-review.md) | AC-008、AC-018、AC-019、AC-020、AC-025、AC-033 |
| FR-18 | 运营、指标负责人 | 用有证据的异常规则定位影响量，提出可分派、可验证的假设。 | [UI-18](../ui/UI-18-diagnosis.md) | AC-021、AC-022、AC-027 |
| FR-19 | 分行运营、指标负责人 | 以业务问题查数、查口径、判断异常或发起专题，并能检查系统理解的范围。 | [UI-19](../ui/UI-19-business-ask.md) | AC-008、AC-023、AC-025、AC-033 |
| FR-20 | 渠道运营 | 用汇总数据估算假设转化率对应人数和差值。 | [UI-20](../ui/UI-20-estimate.md) | AC-024、AC-028 |
| FR-21 | 运营、报告审核者 | 按范围查找报告与修订版本，从已计算结果生成七段式复盘。 | [UI-21](../ui/UI-21-report-list.md) | AC-025、AC-026 |
| FR-22 | 报告审核者 | 审阅正文和来源，签认当前版本，补数后可同时查阅旧报告与新报告。 | [UI-22](../ui/UI-22-report-detail.md) | AC-025、AC-026、AC-030 |
| FR-23 | 运营、行动责任人 | 追踪诊断形成的动作、责任人、期限和复核进展。 | [UI-23](../ui/UI-23-action-list.md) | AC-027、AC-028 |
| FR-24 | 行动责任人、报告审核者 | 把后续的同范围观察和预发回执连回原问题，并保存复核证据。 | [UI-24](../ui/UI-24-action-detail.md) | AC-017、AC-026、AC-027、AC-028 |
| FR-25 | 本机操作员、业务操作者 | 核对导入、计算、回放、报告和导出的任务进展，恢复失败和中断。 | [UI-25](../ui/UI-25-jobs.md) | AC-029、AC-031 |
| FR-26 | 审核者、本机操作员 | 检索业务来源、确认轨迹和导出记录，供他人按原条件复核。 | [UI-26](../ui/UI-26-evidence-export.md) | AC-030、AC-031、AC-034 |

## 非功能需求

| 编号 | 主题 | 可验证目标 | 检查 |
|---|---|---|---|
| NFR-01 | 隔离与身份 | 会话、作用域、Origin/Host 和导出权限 | AC-001、AC-034 |
| NFR-02 | 金额与可重复计算 | 相同输入、规则、数据和口径得相同业务投影 | AC-008、AC-013、AC-022 |
| NFR-03 | 故障恢复 | 租约、幂等、任务中断、备份与恢复 | AC-029、AC-031 |
| NFR-04 | 可追溯 | 从指标、差异或签认回到版本、源行和摘要 | AC-006、AC-026、AC-030 |
| NFR-05 | 运行范围 | 本机断外网可操作，启动及依赖可重现 | AC-001、AC-035 |
| NFR-06 | 响应与容量 | 按运行目标采 P50/P95、RSS 和错误率 | AC-029、M5 性能 |
| NFR-07 | 一致交互 | 清楚展示缺项、版本、错误和键盘状态 | AC-032 |
| NFR-08 | 契约兼容 | 锁文件、Schema、DDL 及状态变化同步验证 | AC-035 |
