# 本机运行与数据保护

## 会话和作用域

首版以本机当前 OS 用户操作。生产式本地运行只绑定 127.0.0.1，启动参数和健康检查以实际绑定地址为证据。每次进程启动生成一次性入口令牌，启动器通过 URL fragment 交给本机浏览器。浏览器取 fragment 后清理地址栏，通过同源请求换会话。服务端会话 cookie 使用 HttpOnly、SameSite=Strict，随机会话标识只在当前进程有效。令牌一次使用、有效期 60 秒、内存存放。每次 unsafe 请求校验准确 Origin 和 Host。仅允许实际启动的回环源；浏览器跨源访问、未知 Host 和过期会话返回拒绝。由发布配置统一服务源、路由和端口。

所有业务对象使用 `workspace_id` 隔离。URL 与请求体出现的对象引用均在服务端校验其归属，外工作区对象按 404 返回。业务确认记录本机操作者、业务角色、时间和范围。合成或授权脱敏标签从工作区传到导入、报告和导出。正式行内数据的授权主体、保留期限、分发权限由行内责任方提供。

## 文件处理

按内容类型、实际解析结果、文件大小和数据结构校验。普通上传限制单文件 64 MiB，合成 v0.1 文件入口限 8 MiB。导入使用生成的制品名，用户文件名仅作显示。CSV 用 UTF-8 或 UTF-8 BOM，导出对可能成为表格公式的字符串做安全转义，数值保持数值。摘要、错误报告和日志仅保存必要字段、行号和受控对象引用。文本以纯文本显示，报告渲染禁用原始 HTML。制品路径使用受控目录和 ID 解析。

## 运行与备份

| 项目 | 运行要求 |
|---|---|
| 数据目录 | 由 `CAMPAIGNLAB_DATA_DIR` 指定，包含 state、raw、snapshots、results、exports、tmp、logs。默认放在当前用户可控目录 |
| SQLite | 每连接启用外键和 5 秒 busy timeout。默认回滚日志 DELETE。测试后可评估同机 WAL 模式与目标运行包 SQLite 版本 |
| 日志 | 结构化时间、request_id、workspace_id、operation、result_code、耗时。源码样本、客户标识、密钥及会话令牌留在受控路径 |
| 备份 | 暂停新写入并等待或取消运行任务，使用 SQLite backup API，复制被引用制品和摘要清单，同一批次写 backup_manifest.json |
| 恢复 | 解至新目录，核对 SHA-256 与 DB foreign_key_check、integrity_check，检查快照、报告及证据引用，按版本迁移后通过只读核查再切换 |
| 清理 | 只清理超期临时件与没有记录引用的制品。签认和已发表结果保留关联证据。状态与文件保留策略写入运行配置 |
| 资源基准 | 在 4 vCPU、8 GiB RAM、SSD 合成环境建立目标测量。10 万行事件、1 万行聚合切片的导入与计算分别记录 P50、P95、峰值内存 |
| 发布测量 | 小样本首页结果 P95 ≤ 2 秒、典型 1000 案例批次 ≤ 60 秒、受控 10 万行导入 ≤ 60 秒作为首轮工程目标。测量口径见验收，结果随环境报告 |

配置变更有诊断页和重启自检。离线运行的静态资源和依赖来自本机已安装包。开放内网服务、多人身份和跨机构权限作为下一部署裁定。
