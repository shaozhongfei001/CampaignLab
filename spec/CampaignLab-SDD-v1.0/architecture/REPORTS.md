# 报告、签认和行动复核

## 报告数据与版本

报告输入为已有 review_id，按需关联同一范围的 diagnosis_id、已执行 question_id。用户可指定标题、普通复盘、专题或产能诊断类型。诊断未选时按默认阈值计算并保存使用版本。专题报告保留问法分组和范围。快照、原值、可比子集、比较基准和取数缺项固定进正文及附录。

| 章节 | 内容 |
|---|---|
| 执行摘要 | 有效触达、最低层、产能三条摘要及异常对象、阈值、影响与来源 |
| 分行策略参与度 | 本次、全行及分组的部署与覆盖，显示月增和环比 |
| 分行策略执行情况 | 五层、层间率及相对基准变化 |
| 分行策略执行效果 | 余额增量、销量及总行下发、分行自主 |
| 异常归因 | 量率、维度、趋势、余量与业务假设，专题对照放在本章子节 |
| 行动建议 | 责任、期限、预期、案例引用与复核方式 |
| 附录 | 范围、快照、口径、阈值、数据截止、源批次、输入和计算摘要、缺项及证据链接 |

MISSING 为 DATA_REQUIRED，只生成取数清单。PARTIAL 或必要产能字段不齐为 PARTIAL_DRAFT，明确可比子集和待补。完整可比、实际基准、必要指标及来源齐备为 DRAFT_READY。必要字段为本期五层和可经营、基准漏斗及本期 AUM、存款、理财、基金、个贷与五项销量。选择目标基准可出对照草稿，签认条件仍要求实际基准。

## 签认和更正

签认匹配报告内容摘要和 If-Match，记录 signer、actor_id、时间、证据和备注。提交后状态 SIGNED。签认绑定已经生成的内容和证据，老版本在数据修订后仍可查看和导出。补数后新报告引用 previous_report_id 并填写 revision_reason，与原报告并列。新报告必须使用更正链上已发布快照或同范围经确认的新快照。差异显示变化值和相关源切片。

## 行动闭环

| 状态转换 | 条件 |
|---|---|
| OPEN → IN_PROGRESS | 已明确责任、验证方式及到期日 |
| IN_PROGRESS → WAITING_VALIDATION | 登记验收案例或写明观察计划及证据 |
| WAITING_VALIDATION → VERIFIED | 用后续同范围 Review 和复核说明，观察可比且证据齐备。MATCHED 另需有效预发与版本回执 |
| VERIFIED → CLOSED | 审阅确认。needs_review 必须 false |
| OPEN、IN_PROGRESS、WAITING_VALIDATION → CANCELLED | 必填取消说明 |
| VERIFIED 或 CLOSED 受更正影响 | 保持原状态与历史，needs_review=true，复核完成后清除该标记 |

改进记录支持 30 或 90 天检查点。due_on 可录入具体日期，默认按创建时业务日期加检查天数，用户可修改。每条保留来源 review_id 和异常证据。复核提交若缺可比数据，保留 NEEDS_MORE_DATA 并列补数项。观察报告只陈述记录事实。实验结论另附分组、统计范围、观察期、指标定义、效应及不确定性、审核记录，首版提供来源记录和导出证据关联。

## 导出

REPORT_MD 导出指定版本 Markdown，PARTIAL_DRAFT 标记草稿。DATA_REQUIRED 导出 MISSING_CSV。REVIEW_CSV 导出当前聚合和可核对依据。EVIDENCE_ZIP 由制品清单、公开范围内的报告或结果、规则版本、案例输入摘要、预期及预发对照、证据索引组成。清单记录文件名、大小、SHA-256、对象引用、生成时间和权限范围。授权脱敏工作区的导出以已授权聚合或最小字段为默认，受保护内容留在原工作区。

未签认报告在底层快照被同范围更正且更正命中时显示 stale。签认命令在事务中复核最新更正和当前摘要，过期返回 409 SNAPSHOT_SUPERSEDED，指引使用新快照重新生成。已签认报告的状态与历史内容保持原版本。VERIFIED 的转换由 reviewAction 执行，普通 transitionAction 用于开始、待验证、关闭和取消。
