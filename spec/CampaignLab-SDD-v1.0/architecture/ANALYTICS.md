# 指标、复盘与问答计算契约

## 指标与范围

[指标字典](../fixtures/metric-dictionary.json) 含完整 ID、名称、公式和单位。六层集合包括可经营和五层漏斗。已部署分行数取 sent 大于零的分行去重。下发策略数按月与策略去重。名单执行率 executed/success，触达率 contacted/success，有效触达率 effective/success，有效接触层间转化率 effective/contacted。覆盖率 success/eligible。分母为零或缺失时返回 null 和具体状态。余额增量、销量按不同指标列展示。

Scope 指定快照、月、渠道、机构、支行、策略来源、策略、客群口径、活动、截止日和基准。空数组表示该维度全部。切工作区和快照后清除失效引用。活动匹配要求绑定起止日覆盖所选数据截止并引用策略版本。缺有效绑定返回 MISSING 和关联取数清单。展示本期、可比本期、基准及差值时，范围和口径并列。

| 比较基准 | 定义 |
|---|---|
| previous、yoy | 上一月、去年同月。年度已选月份分别比去年对应月，显示已覆盖月份与缺口 |
| custom、branch | 指定基准月，或同月指定另一分行。单月自选基准须提供 period，指定分行须提供 branch_id |
| peer、bank | 同组其余分行等权，全行分行等权。逐分行先完成口径对齐。缺参照分行或不能完整对齐时返回缺项。组内选中多分行时按组样本算基准，组内整体无法剔除单一分行时标签明示 |
| hq、target | 同期总行下发策略，或元数据中注明的目标版本。目标仅展示已登记指标，单独标示 |

FULL 为选中范围都配对，PARTIAL 为只有共同子集，MISSING 为没有可用比较。先按当前快照计算原值，再计算对齐子集。缺少比较时仍返回能核实的本期原值。比率差为两比率相减，页面乘 100 以百分点展示。相对变化为差值除以正基准，非正或缺基准不生成相对变化。按两期分别确定分子分母，避免交叉口径。下钻每组可比计算和汇总使用同一范围，排序按数值绝对变化再按稳定键。

## 复盘输出

- 参与度行顺序为本次范围、全行、各组，显示部署机构、策略数、可经营客户、覆盖率和有效触达率。月增与环比专列固定用上月，同页基准字段注明。
- 五层顺序为下发、下发成功、已执行、已接触、有效接触。相邻层以左邻阶段为分母。标亮最低可算层，同值取顺序靠前者。
- 执行效果包含 AUM、存款、理财、基金、个贷余额增量及五项销量。按总行、分行来源拆分。保留负值。
- 明细支持分行、支行、渠道和客群等选定维度。专题展示策略绑定与特色指标。部署客群与月末标签各使用对应源列。
- 证据点开可查看作用域、源切片和批次、口径、截止日期、分子分母和聚合方式。合成样本导出按选择范围与源记录保留定位。

## 异常和归因

阈值版本使用 `mom_pct=10`、`peer_pct=20`、`own_sigma=1`、`layer_pct=15`、`mix_pp=5`。百分比阈值和百分点阈值允许 0–100，标准差倍数 0–10，提交必须正值。每次保存创建新阈值版本。规则仅在相应完整可比且字段可得时判定。

| 规则 | 计算与边界 |
|---|---|
| 期间相对变化 | 正基准，abs((当前−基准)/基准) ≥ mom_pct/100，排除相等，遵守方向 |
| 同组下偏 | 正同组基准，当前低于基准，(基准−当前)/基准 ≥ peer_pct/100 |
| 自身近六月 | 六个完整可比基准月，以总体标准差计算，σ>0 且均值减当前 ≥ own_sigma×σ，要求当前低于均值 |
| 层间同组下偏 | 对下发成功率、执行率、接触层间率、有效接触层间率使用同组下偏，阈值为 layer_pct |
| 结构占比变化 | 以渠道、客群或支行分组各自有效接触计次为分子，分组计次合计为分母。与上月同口径占比差的绝对值达到 mix_pp/100。两期分母须为正。没有记录的分组仅在明确覆盖时取零 |

漏斗量率使用 `sent × successRate × execution × contactConv × validConv`。按这个顺序逐项替换前期值，每次乘积差为贡献。内部 Decimal 运算精度至少 34 位，输出保留到可序列化精度并记录余量。主样例为 +384、0、−144、−432、0 合计 −192。支持分析优先项和趋势，任何推断作为待核假设输出。维度拆解按同范围子集分别聚合。率类分项用维度分子除以各期总体分母，计数与金额用子集量。总变化减去可计算分项作为余量，列交叉覆盖、缺源等原因。存款类型按活期和定期，不能核对加总时保留差额。缺值不能当作零，明确未发生的范围例外。

情景估算以本期 executed 和 validConv 固定，将假设的接触层间转化率限制在 0–1。结果按半入取整到人，返回精确值、取整值、基准实际和差值。0.45 的合成样例得 1,944。展示标签为「条件试算」。11 月实测样例是另一份观察，结论层保留证据种类。

## 业务问答

只接受业务问题或手选意图参数。interpretQuestion 使用 NFKC、空白归一、指标最长别名优先、词典机构与渠道识别、限定月份和比较词、显式比较运算符。使用当前范围为上下文。精确登记问法采用 [问法样例](../fixtures/questions.json) 中的计划，业务数据仍按输入快照执行。机构不存在、指标歧义、策略缺失或范围互相冲突返回 CLARIFY 和具体缺项。先展示计划，用户可改范围并执行 executeQuestion。题述数值作为 claims 供复核，数值以源数据为准。后端仅从白名单模型构造计算请求。

| 意图 | 结果 |
|---|---|
| VALUE | 当前与基准、条件筛选、分组及排序 |
| DEFINITION | 公式、分母、口径和证据 |
| ANOMALY | 规则、对象、阈值、影响 |
| ATTRIBUTION | 统计拆解、余量、待核假设 |
| COMPOSITE | 先查数、再按组合条件判异常及拆解。仅当有异常且 conditional_attribution 开启时才进一步归因 |
| REPORT | 解析范围并执行，允许创建对应类型报告，保留问法来源 |

多分行或多渠道分组按请求范围逐项计算。只允许已登记指标与受控筛选。金额阈值换算为分，比率用小数，人数用人。对相同快照和计划，两次执行的业务结果一致。参照原型 60 条问法及验收表，首版使用这批样例覆盖实际计算和待澄清分支。
