## v1.0.1 补丁：全行月度经营复盘

本节适用于显式选择 `BANK_MONTHLY_V1` 的计算。前文是 v1.0 常规复盘契约。设计依据和行内待核口径见 [来源与决策](../reference/EVIDENCE-AND-DECISIONS.md)。导入、接口与报告见 [月报实施契约](MONTHLY-REVIEW.md)，用例见 [验收清单](../qa/CampaignLab-Review-Acceptance-Checklist.append.md)。

### 1. 计算范围和数据就绪

- 同一工作区、银行、已发布快照、自然月月结。选中月为焦点月，固定取前两个月及焦点月，时间从早到晚。基准为上月，另算焦点月相对前两月的对比。按 Asia/Shanghai 的业务日期识别月末。跨年照自然月回退。各月独立去重。
- 月报总览为全行全渠道全策略。下钻按同一月报结果的渠道、归属分行、分组、客层或新老客读取。下钻控件不重置总览。日粒度、任意基准、策略或客群筛选仍从常规复盘进入。
- 同月客户身份以 `(workspace_id, bank_id, period, customer_key)` 为统计键。客户键是工作区内授权化名，由数据方证明覆盖各渠道和总分行。触达采用 v1.0 明细切片与 `DISTINCT_CUSTOMER` 的五层 0/1 旗标。覆盖缺失、聚合表、作用域不可核或身份不一致时，对受影响的全行唯一人数和产能出待补。没有稳定键的普通复盘仍按 v1.0 的三种模式工作。
- 覆盖表每个 `period × channel` 独立。只有月末、覆盖状态为 `AVAILABLE` 或 `RESTORED`、定义与来源齐备的渠道纳入当月已采集范围。未声明、未采集或非月结为缺数据。只有明确覆盖且无命中才出 0。已采集范围为全六渠道时可称「全渠道」，否则称「已采集渠道」。
- 金额在服务端用整数分，比例和比值用 Decimal（内部精度 ≥34）。复用 Measure 的字符串值，最多 18 位小数，舍入 HALF_UP。页面人数为户，金额由分统一换算元/万元，金额类型随单位写清。份额和率差以百分点显示。正基准才计算相对变化。分母为 0 返回 `ZERO_DENOMINATOR`，输入或指标缺失返回 `MISSING`，基准语义不一致返回 `NOT_COMPARABLE`。任何缺值保留 null、缺项位置及补数说明。

### 2. 三月触客趋势与覆盖变化

记 (E(p,S)) 为月 p、渠道集 S 内 `effective=1` 的客户并集。每月渠道行分别计算有效客户数，银行行求并集。渠道行会包含共同触达客户，渠道行之和只能作渠道计次。

1. **观察值。** 每月用自己的已采集渠道集。显示实际覆盖渠道和缺口，企微在缺采月显示空值和原因。恢复采集月可同时展示企微原值及「恢复采集」标记。
2. **两月可比值。** 焦点与每一基准独立计算共同渠道。要求两月该渠道已采集、`semantic_key` 一致、均为月结，且两月全行统计范围键 `scope_key` 一致。保留两边已采集原值；从共同渠道重新做两边的客户并集。六渠道全配对为 `FULL`，非空真子集为 `PARTIAL`，无共同渠道为 `MISSING`。每个渠道可在相同条件下单独查看原值、差与原因。
3. **三月同口径趋势。** 三月都可比的渠道取同一个交集，三点用它逐月重新去重。没有三月共同集时不画可比折线；未采集断点保持断开。
4. **范围变化桥。** 当两边观察与共同子集均有值，且全行 `scope_key` 相同，显示 `观察差 = 可比差 + 覆盖/口径范围差`。范围差等于 `(焦点原值−焦点共同值)−(基准原值−基准共同值)`。交集计算已吸收渠道重叠。范围差只描述报表范围差异。季末冲刺、企微带来的实际业务增量和资源边际收益登记为待核假设。未采集月无实验分组或观测时，A/B 结论栏留空。

### 3. 参与度与双覆盖率

- 月内至少一条 `sent=1` 的分行算参与分行。策略数用 `strategy_id` 去重；分行策略数按 `(branch_id,strategy_id)` 去重；组均策略数以已参与分行为分母，分母和分行数同屏。此处用切片执行分行。
- 客户覆盖率使用月度客群清册，分行归属取该月清册的 `home_branch_id`。分母 U 为范围内 `eligible=true` 去重客户集。S 为范围内命中 `sent=1` 的客户集，T 为命中 `success=1` 的客户集。策略下发覆盖率 `|S ∩ U| / |U|`，成功下发覆盖率 `|T ∩ U| / |U|`。展示 S、T 的原人数、分母及超出可经营池的排查项。至少一个渠道缺覆盖时，出「已采集渠道覆盖」和缺项，避免当作全渠道完成率。
- 银行默认展示全部策略。分行和分组同时提供「全部策略」与「仅分行策略」视角。后者先筛切片 `origin=branch`，分母仍为同一分行可经营池。组内覆盖率为分行覆盖率等权平均，明确参与计算分行数及无分母分行数。全行覆盖率直接在全行集合算；不平均分行值。两月覆盖差只有全行范围、渠道覆盖/语义及 `eligibility_key` 一致且双方清册完整时可算；群组名单变化通过 `scope_key` 判定。
- 常规复盘沿用 `success / eligible` 与 `effective / success`。示例 A-001 原范围中两个覆盖值是 `12000/15750 = 76.19%` 和 `11520/15750 = 73.14%`，有效触达率仍是 `1728/11520 = 15%`。月报使用清册求交集的补充口径及单独指标 ID。

### 4. 渠道容量与产能

对每个月和渠道分别列已授权容量、实际使用量、有效触达户数、利用率、每单位有效触达和触达客群产能。使用量和容量来自同一源、单位和周期。容量满负荷只由实际使用量和容量比值表示。

| 量 | 计算 |
|---|---|
| 容量利用率 | `used / capacity`。零容量为 null，超容保留真实比率并标注。远程和 AI 外呼使用 `CALL_ATTEMPT` |
| 每单位有效触达 | `渠道有效客户数 / used`，单位随使用量显示「户/拨打次」等。即使大于 1 也保留实值并提示核对。接通率另按常规复盘漏斗定义 |
| 渠道触达客群产能 | 对该渠道有效客户集合汇总客户月度净余额增量和销售额。AUM 客均 = 该集合 AUM 余额增量 / 该集合客户数，单位分/户。跨渠道同一客户可重复，渠道列禁止相加成全行产能 |

相对上月效率变化需容量 `semantic_key`、单位、触达口径和月结范围同时相同。AUM 与销量要两边相同 `outcome_key` 和客户范围；本期产能可以在不可比时独立展示。远程/AI 缺容量，或触客增长与产能增幅背离，分别触发补数或业务核查线索。默认用「观察」表述，带分子分母、期间和来源。

### 5. 客群结构与产品产能

- 一份月内清册最多一条客户记录。客层、归属分行按月末记录。新客为银行按当年首个有效建客日确定的 `NEW_YTD`，其余为 `EXISTING`；定义或日期缺失时取 `UNKNOWN`。不能用首次活动日期代替。首版样例以显式标签输入。
- 在全渠道有效名单与完整活动清册都齐备时，对月度全行客户按 `策略有效触达 > 客户经理自主盘点 > 自主活跃 > 其他/未归类` 互斥归类。后二者来自明示来源，单凭没有策略记录不能归入自主活跃。该优先级为本补丁的合成规则。覆盖不足时，可显示已观测策略客群的指标；全部来源结构、占比及其跨月变化留空并列补数。
- 分别提供全行来源结构（含未归类）、策略有效客群按客层拆分、策略有效客群按新客/存量拆分。首版固定维度，不做任意交叉切片。策略有效触达的某客层覆盖分母为同月清册该层全部客户，另可查看可经营分母，二者按指标名区分。
- 按客户集合汇总客户-月-指标的权威金额。AUM、存款、理财、基金、非货币基金、保险等**余额增量**与五项**销量**分别成组。非货基、非现金管理类为各自父项子集，不能重复计入合计。非核心或未提供的指标展示缺项，金额可加条件以已公布的 `outcome_key` 及指标字典为准。样例以金额示范复算，正负保留。
- 来源结构的产能占比分母为全行同指标同月份；策略客层和新老客的产能占比分母为全行策略有效客户同指标同月份。只有总额为正且完整才出份额。对同一客户月不同产能记录，源方须先提供已核的唯一净额，合并多源需保留来源，冲突阻止该输入发布。

### 6. 总分行重复触达与产能核对

令 H、B 分别为同月有效触达的总行与分行策略客户集。使用 `origin` 映射判定，和执行机构、客户归属分行分开。按同客户键建立三个互斥集合 `HQ_ONLY = H − B`、`BRANCH_ONLY = B − H`、`BOTH = H ∩ B`，`UNION = H ∪ B`。人数和同一客户-月-指标权威金额均只计一次。三个互斥项和等于去重总额，保留负贡献。金额带原始来源证据。

同时给「分行触达口径（含共同触达）」=`BRANCH_ONLY + BOTH`，以复核手工报告的历史口径，分母为 UNION；注明口径含重及重叠金额。分母不正或不可得时份额为空。历史比值与去重产能并列。去重产能回答「这批客户净额多少」，不自动分配给某个渠道或策略，也不陈述因果。

全六渠道覆盖、同一月闭合的总分行策略来源、跨机构稳定客户键为互斥集合的前提。覆盖或键不足时同时隐藏三类拆分和去重总额，只保留能核实的原口径与待补项。金额缺值只阻断对应指标，不清空可核人数。聚合行不能用总行金额加分行金额推断去重全行。

### 7. 结论、签认和复核

每条结果携带期间、快照、覆盖、定义与来源证据。每条业务观察附对比范围与变化。优先核对项包括企微恢复范围、渠道接近容量上限时的单位触达、触客与产能背离，以及重复触达金额。可能的解释记录为待核假设。人工选中证据创建改进项，填写责任人、期限、验证口径和计划。使用同一月报指标及可比范围提交下期观察；效果归因另需受控实验资料。

月报就绪与普通 Review 状态分开。焦点月无可核触客时为 `MISSING`。有触客但三月缺覆盖或可比、完整清册/活动来源缺失、关键产能或容量缺失时为 `PARTIAL`。全部就绪才为 `FULL`。具体必需字段、状态、报告与导出见 [月报实施契约](MONTHLY-REVIEW.md)。金额缺项、渠道定义冲突或跨行不可比均在对应证据中留痕。
