# 月报页面增量契约

保持基座 12 栏布局、主题、数据密度、键盘、加载和证据抽屉规范。画面所有数值来自同一份月报结果。金额、人和百分比按指标定义显示，缺值用「—」和原因。

## UI-17 策略复盘 · 全行月度经营复盘

**路由** `/w/:workspace_id/review?view=monthly`。现有导航「策略复盘」下显示「常规复盘」和「全行月报」，默认常规；刷新保留视角和已选参数。切换工作区清理快照、数据和证据抽屉。

| 顺序与区域 | 画面、状态与操作 | 绑定 |
|---|---|---|
| 范围条（12 栏） | 快照、焦点月、月结日期、基准窗口，按钮「计算月报」「生成报告」「导出数据」。三月固定并显示。标注来源为合成或授权脱敏 | listSnapshots、runReview.profile、getJob、getReview |
| KPI（四张各 3 栏） | 焦点月有效触达客户数、共同范围环比变化、策略下发覆盖率、成功下发覆盖率。触客范围不足显示「已采集渠道」 | trend、comparisons、participation |
| 趋势与差分（左 8、右 4） | 三月原值及同口径趋势，两序列分别图例。缺采点断开。右侧将观察差、共同范围变化、覆盖范围差放在同一列。点击「企微恢复」展开两月覆盖定义与来源 | trend、comparisons、getEvidence |
| 渠道与分行（全宽两标签） | 六渠道固定顺序，容量、使用、利用率、有效户、每单位有效触达、AUM 及客均。分行标签切换全部策略/仅分行策略，显示部署机构、策略及覆盖率的分子分母。汇总、分组、分行分别有行类型 | capacity、participation |
| 客群和产能（12 栏） | 「来源结构」「客层」「新客/存量」三视角。金额表可切换余额增量/销量。负数保留；非货基等子项缩进；未知类可见 | production、months 对应证据 |
| 总分行核对（12 栏） | 五行依次仅总行、仅分行、共同、去重合计、分行含重。显示人数、AUM 与销量，最后一行的占比写明分母。缺身份或覆盖时显示「待补去重依据」 | origin_overlap |
| 优先核对与证据 | 从差分、容量、产能点「查看依据」。抽屉给期间、覆盖、公式、源位置及权威定义。可从可定位的观察证据「新建改进项」 | getEvidence、createAction |

顶部状态为 `FULL/PARTIAL/MISSING` 的中文映射「数据齐备/部分可用/待取数」。PARTIAL 展示已知数据，比较和图表标明有效范围；MISSING 保留范围条与取数入口。生成报告：FULL 生成可签认草稿，PARTIAL 生成部分草稿，MISSING 生成取数清单。所有请求固定所选快照，作业切换焦点后仅回填匹配的发起范围。旧快照保留只读查看入口。

## UI-21 报告列表与新建

**路由** `/w/:workspace_id/reports`。从月报进入时默认「全行月度经营复盘」、选中当前 Review 与月份，提交 TOPIC。取消不改变当前复盘。列表使用原筛选和分页，按报告标题显示「月度经营复盘」及业务月份；详情用原操作。常规专题保留自己的问法与样式。

## UI-22 报告审阅、签认与修订

**路由** `/w/:workspace_id/reports/:report_id`。摘要条固定显示焦点月、三月范围、快照、已签/部分草稿等。左 3 栏放七章和版本链，右 9 栏正文，按 [实施契约](../architecture/MONTHLY-REVIEW.md#3-报告正文签认补数) 渲染。

- 部分草稿展示影响章节、取数清单和补数入口。待取数只显示清单。签认按钮同时满足 `DRAFT_READY`、`stale=false` 与已有证据。签认失败保留草稿，提示刷新或去新快照生成修订。
- 旧签认打开原快照内容与摘要。相邻版本对比给变更字段、前后值和受影响来源。生成修订从新快照计算月报后填 `previous_report_id` 与原因。REPORT_MD、MISSING_CSV、证据 ZIP 按原按钮触发。
- 正文把观察、待核原因、行动、实验四种内容标注清楚。口径恢复不能通过文案生成实验结论。
