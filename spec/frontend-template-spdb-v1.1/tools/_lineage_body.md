**本轮学到的三条（已固化成门禁，不再靠人记）**

1. SVG 图表是 `width:100%` 弹性项，放进 `.flex`／`.two` 会抢满宽度、把兄弟节点压成 0 宽
   → 小图（donut/radar/spark）必须定宽包裹，构建期已加检查。
2. `a +` 换行 `+ b` 会被解析成 `a + (+b)` 产生 NaN → 构建期扫描「行尾+ 接行首+」。
3. 上一轮交接摘要里的图表签名有两处是错的（`radar` 是 `items:[{l,v}]` 且 v 为 0..100；`donut` 无 `size` 选项），
   `hbars` 也不支持负值。**一律以母版源码为准**，模板文档已按源码逐条核对并写明限制。
