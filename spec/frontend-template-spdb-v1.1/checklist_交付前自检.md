## E. 已知会咬人的环境坑（写代码前先读）

1. PowerShell 5 **不支持 `&&`**；外层 `powershell -Command "…$x…"` 会吞 `$`。
2. PS here-string `@' … '@` 里 `\"` 会原样保留；多行内容先写文件再执行。
3. 中文读写统一 `$env:PYTHONIOENCODING='utf-8'` + `python -X utf8` + UTF-8 无 BOM；URL 中文用 `encodeURIComponent`。
4. Playwright：`PLAYWRIGHT_BROWSERS_PATH` 要指到 Codex 包缓存；`page.$x` 已移除；同 URL 只改 hash **不会重跑脚本**，需 `page.reload()`。
5. 截图路径不要用 URL 编码后的中文串当文件系统路径（会在 `D:\ws\codex` 下生成 `%E6…` 目录）。
6. Python 里生成 JS 时：字符串内不能出现真换行；含 `%` 的 JS 模板不要用 `%` 格式化。
