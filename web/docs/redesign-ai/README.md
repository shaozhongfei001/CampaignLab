## 0. 一句话定位转变

从「**人找数的 BI 报表工作台**」升级为「**数找人 + 对话驱动的 AI 复盘分析操作系统**」：
指标数据仍是地基（保留），但主交互变为 **对话 + 分析画布**，复盘由 **智能体自动完成** 并主动推送，人只做 **签认与决策**。

## 2. 设计原则

1. **四段式回答**：任何 AI 结论一律按 讲演稿范式输出 ①指标判断 ②结构拆解 ③归因分析 ④决策建议（M1/M2/M4 一致）。
2. **受控链路可见**：语义解析→查询规划→指标映射→SQL 生成→结果校验→分析解释 六环节可展开（M1 一行迹 / M3 全迹），银行场景必须可解释。
3. **每个数字可回溯**：指标对象 + 口径版本 + 快照 + 证据角标（`.ref`），点击进证据；缺数显示「—」不用 0 顶替（模板红线）。
4. **报告是入口不是终点**：报告拆成 指标/结论/归因/建议 四类结构化块，段级可追问、可重生成、可沉淀为组织资产（M4）。
5. **人只做签认**：智能体产出建议/改进项默认待签认，未签认不得提交（沿用模板「未确认前不得提交」红线）。
6. **视觉不换肤**：全部沿用浦发模板令牌；仅新增 `--ai-*` 智能体强调色，且**只用于 AI 生成态/流式态/智能体入口**，不作品牌色、不作语义色。
